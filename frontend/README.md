# UrbanTrack AI — Frontend Operations Console

This is the Next.js 16 operations dashboard for **UrbanTrack AI**, providing visualization, vehicle exploration, trajectory tracking, and forensic investigation interfaces.

## Tech Stack
- **Framework**: Next.js 16 (App Router)
- **UI Library**: React 19
- **Type Safety**: TypeScript 5
- **Styling**: Tailwind CSS 4 (Dark mission-control palette)
- **Data Visualizations**: Recharts, Three.js, Leaflet
- **Icons**: Lucide React

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm run dev
```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Environment & Backend Connection
By default, the frontend connects to the backend API running on `http://localhost:8000`. Ensure the FastAPI backend is running for live data feeds and authentication.
